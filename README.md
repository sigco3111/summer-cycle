# 여름 자전거 (Summer Cycle) 한국어판

늦여름 일본 시골길을 자전거로 달리는 Three.js 기반 3D 탐험 게임입니다. 논, 오래된 목조 가게, 전선과 산을 지나며 오후부터 해질녘까지 변하는 풍경을 감상합니다. 점수나 승패는 없습니다.

[StarKnightt/summer-cycle](https://github.com/StarKnightt/summer-cycle)의 한국어 포크입니다. 원작의 수채화풍 그래픽, 캐릭터, 물리와 사운드는 유지하고 화면 안내와 조작법, 일시정지 메뉴, 간판을 한국어로 바꿨습니다.

![시골길 자전거 여행](media/reel.webp)

## 한국어판 변경 사항

- 제목, 설명과 공유 미리보기 메타데이터, 로딩 단계, 출발 안내 번역
- 일시정지 메뉴와 키 설명, 둘러보기·다시 타기 안내 번역
- WebGL 실행 오류와 새로고침 안내 번역
- 과자 가게, 라멘, 소바, 정류장, 공중전화, 채소 가판대 등 코드로 그리는 간판 번역
- 한국어 시스템 글꼴 우선 적용. 일본 배경과 고유명사는 유지하며 가격은 엔 단위를 유지합니다.
- 원본 문서는 [README.en.md](README.en.md)에 보존합니다. LICENSE, 제작 요구사항과 개발 문서는 원문을 유지합니다.

## 권장 환경

**데스크톱 GPU와 최신 Chrome 또는 Edge를 권장합니다.** 원작은 Chromium 기반 브라우저에서 개발·측정되었으며 Safari와 Firefox는 미검증입니다. 별도 모바일 조작이나 모바일 저품질 모드는 없습니다. 한국어 간판을 표시하려면 시스템에 한글 글꼴이 있어야 합니다.

## 조작법

| 입력 | 동작 |
|---|---|
| 클릭 또는 아무 키 | 출발, 첫 입력 후 사운드 시작 |
| 마우스 | 주변 둘러보기 |
| W / 위쪽 화살표 | 더 세게 페달 밟기 |
| S / 아래쪽 화살표 | 브레이크, 정지 후 뒤로 이동 |
| A D / 좌우 화살표 | 방향 조절 |
| Shift | 자전거 전력 질주 / 도보 달리기 |
| F | 자전거에서 내리기 / 다시 타기 |
| C | 추적·정면·측면 카메라 전환 |
| V | 1인칭 / 3인칭 전환 |
| T | 오후 → 황금빛 시간 → 일몰 → 땅거미 전환 |
| B | 자전거 벨 |
| M | 음소거 |
| Esc 짧게 | 일시정지 / 계속 |
| Esc 길게 | 마우스 해제, 전체화면 해제 |

일시정지 화면에서는 클릭, Enter, Space로도 계속할 수 있습니다. 탭이나 창을 바꾸면 자동으로 일시정지됩니다. 자전거에서 내린 뒤에는 WASD로 걷고 마우스로 시점을 돌리며 휠로 확대·축소합니다. 자전거에서 멀리 떨어졌다면 F로 자전거를 가까이 불러올 수 있습니다.

## 로컬 실행과 빌드

Node.js 22와 pnpm 10.18.3을 준비합니다.

```bash
git clone https://github.com/sigco3111/summer-cycle.git
cd summer-cycle
pnpm install
pnpm dev       # http://localhost:5421
pnpm build     # TypeScript 검사 후 dist/ 생성
pnpm preview   # http://localhost:5420
```

이 프로젝트는 TypeScript + Vite를 사용하므로 소스 `index.html`을 그대로 정적 호스팅하면 실행되지 않습니다. **빌드된 `dist/`를 배포해야 합니다.** Vite의 상대 경로 `base: "./"` 덕분에 GitHub Pages의 저장소 하위 경로에서도 실행됩니다.

`.github/workflows/pages.yml`은 `master` 푸시 또는 수동 실행 시 pnpm 설치, 타입 검사, Vite 빌드를 수행하고 `dist/`를 Pages로 배포합니다. 저장소의 Settings → Pages에서 Source를 GitHub Actions로 설정합니다.

## URL 옵션

| 옵션 | 효과 |
|---|---|
| `autoplay=1` | UI 없이 자동으로 자전거를 탐 |
| `skipintro=1` | 생성이 끝나면 바로 출발 |
| `time=golden` | 오후(`afternoon`), 황금빛(`golden`), 일몰(`sunset`), 땅거미(`dusk`) 중 시작 시간 선택 |
| `timelapse=1` | 약 40초 동안 오후에서 땅거미까지 변화 |
| `cam=fpp` | 1인칭으로 시작 |
| `fs=0` | 출발 시 전체화면으로 바꾸지 않음 |
| `msaa=0`, `2`, `4` | 안티앨리어싱 단계 고정 |
| `kuwahara=0` | 회화풍 필터 끄기 |
| `nohud=1` | 속도 표시 숨기기 |

예: 실행 URL 뒤에 `?autoplay=1&timelapse=1`을 붙이면 시간대가 변하는 자동 주행을 감상할 수 있습니다. 자동 주행도 Esc로 일시정지되며 저절로 다시 시작하지 않습니다.

## 장면과 기술

- 코드로 생성하는 640m 순환 도로와 8개 구간의 거리별 디테일 조절
- 세 단계 툰 셰이딩과 화면 기반 윤곽선
- Kuwahara 회화 필터, 블룸, 종이 질감, 색 보정과 선명화
- 논의 물에 하늘·나무·캐릭터를 비추는 평면 반사
- 네 시간대의 조명과 약 3.6초 전환, 밤의 등불·별·반딧불이
- 페달과 손잡이에 맞춰 움직이는 캐릭터의 역운동학, 머리카락·치마 움직임
- 충돌을 처리하는 도보 탐험과 자전거 탑승
- Web Audio로 합성하는 체인, 바퀴, 벨, 바람, 매미, 새, 개구리와 환경 소리

장면의 모델·텍스처·소리는 실행 시 코드로 생성됩니다. README 사진과 공유 미리보기 이미지는 문서용이며, 게임은 별도 게임 서버를 요구하지 않습니다.

## 성능과 한계

원작 README는 RTX 4060, 1920×1080, MSAA 4x 자동 주행에서 오후 평균 118 FPS, 일몰 116 FPS, 땅거미 112 FPS를 보고합니다. 이는 원작의 측정값이지 한국어판이나 사용자 PC의 측정값이 아닙니다.

- 캐릭터는 코드로 만든 기본 도형을 조합하므로 가까이서는 전문 모델과 차이가 있습니다.
- WebGL 2와 하드웨어 가속이 필요합니다. 다른 무거운 3D 탭을 닫으면 도움이 될 수 있습니다.
- 전체화면·마우스 고정·Esc 동작은 브라우저 권한과 Keyboard Lock 지원에 따라 다릅니다.
- 시스템에 한글 글꼴이 없으면 간판이 네모로 표시될 수 있습니다.
- 모바일 실행과 Safari/Firefox 호환성을 보장하지 않습니다.

## 파일 구조

| 경로 | 내용 |
|---|---|
| `index.html` | 종이 질감 로딩 화면과 스타일 |
| `src/main.ts` | 장면 초기화와 실행 루프 |
| `src/loader.ts`, `src/pause.ts` | 로딩 안내, 일시정지 메뉴 |
| `src/rider/` | 자전거, 캐릭터, 시점, 도보 조작 |
| `src/world/` | 도로, 식생, 가게, 하늘과 시간대 |
| `src/render/` | 셰이더, 간판, 반사와 후처리 |
| `src/sound/` | 사운드 합성과 재생 |
| `scripts/`, `tools/` | 개발용 캡처·측정 도구 |
